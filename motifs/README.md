# MEME/FIMO motif inputs

`family_rules.tsv` freezes the manuscript-active classification thresholds. `meme/` contains deterministic gzip copies of the 19 family-specific MEME XML models generated by MEME Suite 5.5.9. `model_manifest.tsv` records the exact historical command and uncompressed XML checksum for each model.

The GSH2 family has one sequence. MEME/FIMO requires at least two sequences for de novo discovery, so that protein is recorded as not motif-evaluable and retained by the explicit singleton passthrough.

The historical combined run also included 105 AAT candidates that are outside this deposited manuscript package. These files contain only the 20 reporting categories and 975 proteins represented in `data/candidate_stage_ledger_975.tsv`.
